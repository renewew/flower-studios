# flower-studios
Flower Studios es un proyecto escolar creado en 2025.

Se creó debido a un proyecto transversal informático que nos pidió hacer en equipo en 4to semestre para desarrollar un programa de escritorio a una empresa que no contara con algún sistema de información y mejorar la eficiencia de la empresa.

EL nombre del proyecto de la empresa comenzó como "Flower System", pero terminando 5to semestre fue cambiado a "Flower Studios" con el fin de que el nombre se viera mas profesional.

En 6to semestre (Año 2026, Actual.) Se nos pidió desarrollar una página o sitio web, como para la empresa al que le desarrollamos el sistema de información como para la empresa del proyecto, por mas cómodidad elegimos la empresa de proyecto y desarrollamos esta página web.
